# Эксперимент 2 — GBDT на расширенных фичах (EWMA, тренды, декомпозиция, YoY-сезонность)

- **Гипотеза**: поверх базовых оконных агрегатов exp01 прирост дают: рекенси-взвешенные уровни
  (EWMA), тренды/моментум, декомпозиция «частота × чек», доли источников GMV и сезонный
  YoY-индекс (окно сабмита [2026-02-14..2026-03-15] содержит праздники 23.02 и 08.03;
  календарный близнец [2025-02-14..2025-03-15] есть в трейне).
- **Метод**: к 56 базовым фичам exp01 (готовый кэш `data/v2/features/`, реюз read-only,
  джойн по `user_id` — чистая абляция «база vs база+дельта») добавлены 17 новых фичей из
  сырых данных (`archive/exp02/src/exp02_features.py`, батчи по 50k юзеров, только история ≤ якоря):
  EWMA gmv/to_ord c полураспадом {7, 30}д за окно 90d (нормировка на константу полного
  календарного окна); тренды `gmv_7/gmv_30`, `gmv_30/gmv_90` и OLS-наклон log1p(gmv) за 60d
  (n=60 фиксировано, пропуски дают y=0, положительный наклон = рост); конверсии по
  источникам `conv_s2o/conv_c2o/conv_o2c` за 90d (знаменатель 0 → NaN, CatBoost native);
  декомпозиция `aov_30`, `ord_days_30`; `due_ratio` = дней с последнего заказа / медианный
  интервал заказов (история целиком); доли `gmv_search|gmv_cat` за 90d + их тренд 7d−90d;
  перцентильный ранг `gmv_sum_30d` в популяции якоря — считался **в скрипте обучения**
  одним polars-выражением по собранному фолду (популяционная статистика, в батчи не
  выносится). Итого лучший конфиг 66 фичей (56+10), полный 74 (56+17+1).
  Протокол exp01 сохранён: RMSE на z=log1p(target), lr=0.05, depth=8, l2_leaf_reg=3, seed=42;
  трейн fold_00+01+02, вал fold_03; инверсия expm1 один раз, клип ≥0. Дополнительно:
  прокси-фолд с якорем 2025-02-14 (базовые 56 фичей для него досчитаны дословным портом
  кода exp01 — в их кэше прокси нет), YoY-калибровка `ŷ·ŝ^β`.
- **Результат**:

  Абляция фичей (RMSLE fold_03, 1000 iters если не указано):

  | конфиг | блоки | фичей | RMSLE fold_03 | Δ к базе |
  |---|---|---|---|---|
  | база (контроль воспроизводимости) | — | 56 | 1.70284 | — |
  | база + EWMA + тренды | 1–2 | 63 | 1.70304 | +0.0002 |
  | **база + конверсии + декомпозиция + due_ratio + доли** | 3–6 | 66 | **1.69277** | **−0.59%** |
  | полные ×500 | 1–7 | 74 | 1.69545 | −0.43% |
  | полные ×1000 | 1–7 | 74 | 1.69364 | −0.54% |
  | полные ×1500 | 1–7 | 74 | 1.69302 | −0.58% |

  База воспроизвела exp01: 1.70284 против 1.70261 (отклонение 0.00023 ≤ допуска ±0.002).

  Leave-one-fold-out (лучший конфиг 66 фичей против базы 56):

  | holdout | база 56 | лучшие 66 | Δ |
  |---|---|---|---|
  | fold_00 | 1.82900 | 1.81545 | −0.74% |
  | fold_01 | 1.78801 | 1.77420 | −0.77% |
  | fold_02 | 1.72102 | 1.71090 | −0.59% |
  | fold_03 | 1.70284 | 1.69277 | −0.59% |

  Улучшение на всех 4 фолдах, деградации нет.

  Абляция лосса (66 фичей, 1000 iters, fold_03): RMSE **1.69277** ← лучшая;
  Tweedie vp=1.1 / 1.5 / 1.9 → 1.69287 / 1.69339 / 1.69510; MAE 1.80181 (медианный
  предиктор в z проваливает RMSLE). Квадратичный лосс на log1p подтверждён.

  YoY-калибровка: платформенный индекс ŝ = Σgmv[2025-02-14..2025-03-15] /
  Σgmv[2025-01-15..2025-02-13] = **1.16278** (+16.3%). Прокси-фолд (якорь 2025-02-14),
  модель обучена на fold_00..02:

  | β | 0 | 0.25 | 0.5 | 0.75 | 1.0 |
  |---|---|---|---|---|---|
  | RMSLE прокси | 1.85297 | 1.84728 | 1.84235 | 1.83819 | **1.83478** |

  Сетка монотонно убывает, β̂ = 1.0 (argmin по протокольной сетке).

  Финал: рефит лучших 66 фичей (RMSE, 1000 iters) на всех 4 фолдах → честная оценка на
  fold_03 = **1.67165** (exp01 рефит: 1.68125, −0.57%) → предикт fold_end → калибровка
  β=1.0 → `submissions/submission_exp02.csv`: 250 000 строк, порядок как в sample_submit,
  предикты конечны и ≥0 (mean 39.55, median 8.03, max 5156.36).

- **Вывод**: критерий adoption выполнен — 1.69277 ≤ 1.69920 (улучшение 0.59% против
  1.70261 при пороге 0.2%), остальные фолды не деградируют (все улучшились на 0.59–0.77%).
  **Эксперимент засчитан, конфиг принят.** Прирост дали конверсии по источникам
  (`search_to_ord/searches`, `cat_to_ord/cat` — категории в базе отсутствовали),
  декомпозиция «частота × чек» и due_ratio; EWMA и тренды сами по себе вклад не дали
  (блок 1–2 нейтрален, в полном конфиге чуть шумит). Топ-важность возглавили те же
  заказные агрегаты, новые фичи — в середине списка (см. фигуру важностей).

## Артефакты и воспроизведение

```bash
# 1) новые фичи + прокси-фолд -> data/v2/features_exp02/<fold>/batch_*.parquet (~1 мин)
.venv/bin/python archive/exp02/src/exp02_features.py

# 2) абляция, LOFO, лоссы, YoY, фигуры -> archive/exp02/reports/exp02_metrics.json, archive/exp02/reports/exp02_figures/ (~14 мин)
.venv/bin/python archive/exp02/src/exp02_train.py

# 3) диагностика границы β-сетки (опционально, ничего не пишет)
.venv/bin/python archive/exp02/src/exp02_beta_check.py

# 4) рефит + калибровка + сабмит -> submissions/submission_exp02.csv (~2 мин)
.venv/bin/python archive/exp02/src/exp02_submit.py
```

Скрипты идемпотентны (готовые батчи пропускаются), сиды фиксированы (42), все сравнения —
на одном сплите. Встроенные проверки: ассерт отсутствия inf во всех новых фичах; печать
NaN (ожидаемы только `conv_s2o/conv_c2o/conv_o2c/due_ratio` — 1.2–60k строк на фолд по
спецификации); выборочная проверка утечки — новые фичи якоря A побайтово совпадают при
удалении всех строк `event_date > A` (юзеры {2, 457512, 918481}, якоря 2025-12-31 и
2026-02-13); ассерты сабмита как в exp01 (размер, колонки, состав и порядок user_id,
конечность, неотрицательность).

Фигуры: `archive/exp02/reports/exp02_figures/exp02_feature_importance.png`,
`exp02_pred_vs_actual.png`, `exp02_beta_calibration.png`.

## Ограничения и оговорки

1. **β̂ = 1.0 — граничное решение.** Расширенная сетка (до 1.5, `archive/exp02/src/exp02_beta_check.py`)
   показывает монотонное убывание RMSLE прокси и за границей: оптимум вне протокольной
   сетки не идентифицируем. β=1.0 — консервативный нижний выбор в пределах сетки;
   фактический множитель уровня для сабмита ×1.163 может оказаться как недостаточным,
   так и избыточным.
2. Прокси-фолд — слабый аналог продакшена: у юзеров только 45 дней истории (против
   400+ у fold_end), сдвиг дней недели и перенос праздников 2025→2026. β выбран по
   прокси как направленная оценка, не гарантия; RMSLE прокси (≈1.83–1.85) заметно хуже
   основных фолдов именно из-за короткой истории.
3. EWMA нормирована на константу полного 90-дневного окна: молодые юзеры получают
   систематически заниженный уровень (монотонно, для дерева не критично).
4. Рефит-оценка 1.67165 на fold_03 in-sample для рефит-модели (фолд входил в обучение) —
   приведена только для сравнения с аналогичной цифрой exp01 (1.68125).
5. Блок EWMA+тренды оставлен только в полном конфиге и в сабмит не вошёл; его полезность
   стоит перепроверить после тюнинга гиперпараметров.
6. Предикт fold_end экстраполирует на месяц вперёд от последнего обучающего якоря —
   YoY-калибровка частично компенсирует сезонность, но хвостовой риск остаётся.
