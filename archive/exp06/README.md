**Вывод.** Закрыт: пост-обработка поверх готового сабмита не работает. Калибровка полезна только внутри мета-модели стека (exp08, exp15).

## Состав каталога

- `src/` — код эксперимента: `exp06_calibration_indices.py`, `oof_calibrate.py`
- `reports/` — отчёты, метрики, графики: `exp06_calibration.json`

## Как запустить

Архивные скрипты используют относительные пути и запускаются **из корня репозитория**:

```bash
.venv/bin/python archive/exp06/src/exp06_calibration_indices.py
```

Крупные артефакты (parquet-фичи, CSV-сабмиты, чекпоинты) в git не попадают —
регенерируются этим же скриптом. Протокол валидации: [docs/PROTOCOL.md](../../docs/PROTOCOL.md).
