**Вывод.** rejected как соло: потолок семейства «уровень × доля» ≤ −2% RMSLE, и то не на всех фолдах. Польза — только как вход калибровки уровня.

## Состав каталога

- `src/` — код эксперимента: `exp10_decomposition.py`
- `reports/` — отчёты, метрики, графики: `exp10_decomposition.json`

## Как запустить

Архивные скрипты используют относительные пути и запускаются **из корня репозитория**:

```bash
.venv/bin/python archive/exp18/src/exp10_decomposition.py
```

Крупные артефакты (parquet-фичи, CSV-сабмиты, чекпоинты) в git не попадают —
регенерируются этим же скриптом. Протокол валидации: [docs/PROTOCOL.md](../../docs/PROTOCOL.md).
