**Вывод.** Очистка не дала буста (GBDT устойчивы к коррелированному шуму), но датасет полезен как быстрый и стабильный бейзлайн.

## Состав каталога

- `src/` — код эксперимента: `build_dataset_v3.py`, `train_stack_v3.py`
- `reports/` — отчёты, метрики, графики: `dataset_v3_report.json`, `stack_search_v3.json`

## Как запустить

Архивные скрипты используют относительные пути и запускаются **из корня репозитория**:

```bash
.venv/bin/python archive/exp19/src/build_dataset_v3.py
```

Крупные артефакты (parquet-фичи, CSV-сабмиты, чекпоинты) в git не попадают —
регенерируются этим же скриптом. Протокол валидации: [docs/PROTOCOL.md](../../docs/PROTOCOL.md).
