**Вывод.** Лучший CV в репо (1.62463), но LB 1.6862 — переобучение на январскую яму. Бленд 50/50 с чемпионом даёт 1.66.

## Состав каталога

- `src/` — код эксперимента: `per_user_full.py`
- `reports/` — отчёты, метрики, графики: `per_user_full.json`, `per_user_pilot.json`

## Как запустить

Архивные скрипты используют относительные пути и запускаются **из корня репозитория**:

```bash
.venv/bin/python archive/exp23/src/per_user_full.py
```

Крупные артефакты (parquet-фичи, CSV-сабмиты, чекпоинты) в git не попадают —
регенерируются этим же скриптом. Протокол валидации: [docs/PROTOCOL.md](../../docs/PROTOCOL.md).
