## Документы

### `PROTOCOL.md`
Единый протокол валидации всех экспериментов: метрика RMSLE, якоря фолдов,
правила честности (никакой информации после якоря, один набор фолдов для
сравнения, фиксированный сид), референсные точки. Вынесено из
`EXPERIMENTS.md`, потому что это правило, а не результат.

### `DATA.md`
Схема `train.parquet`, конструкция таргета, устройство feature store
(`data/v2`, `data/v3`, `data/segmented_base`), почему тяжёлые файлы не в гите,
как собрать обучающую таблицу.

### `SEGMENTED_PIPELINE_RUNBOOK.md`
Пошаговый запуск сегментированного LTV-пайплайна (exp26): подготовка
окружения, smoke-прогон на 10k, классическая ветка, ветка с Transformer,
финальная проверка сабмита.

### `SERVER.md`
Удалённый сервер: характеристики, установка зависимостей без venv, порядок
rsync, tmux для долгих прогонов, чек-лист расхождения локальных и серверных
метрик.

## Как документы соотносятся

```
README.md          ← точка входа: что это, быстрый старт, статус, ссылки
├── docs/         ← стабильные правила и регламенты
├── notes/        ← живое и незакрытое: бэклог, разборы, инциденты
├── EXPERIMENTS.md← журнал: что пробовали, что выиграло
├── src/README.md ← карта кода
└── archive/expNN/README.md ← карточка конкретного эксперимента
```

Правило разделения: **`docs/` — то, что верно независимо от текущего
эксперимента; `notes/` — то, что может измениться; `EXPERIMENTS.md` — только
результаты.**
