# Протокол валидации

Единый протокол для всех экспериментов репозитория. Журнал результатов —
[../EXPERIMENTS.md](../EXPERIMENTS.md).

## Метрика

```
RMSLE = sqrt( mean( (log1p(y_true) - log1p(y_pred))^2 ) )
```

Лог-метрика ⇒ оптимален предикт условного среднего в z-пространстве
`z = log1p(y)`: квадратичный лосс на z тождественен RMSLE, инверсия `expm1`
применяется один раз в конце.

Абляцией лосса подтверждён квадратичный вариант (exp02): RMSE на z `1.69277`
< Tweedie vp 1.1 / 1.5 / 1.9 (`1.69287` / `1.69339` / `1.69510`) < MAE `1.80181`.

## Правила честности

1. **Никакой информации после якоря.** Фичи, таргеты и обучение — строго по
   историю до якоря. Фичеры (`pca`, `btyd`, `exp17`, segmented) обучаются на
   train-фолдах и для `fold_03`/`fold_end` — чистый transform.
2. **Сравнение конфигураций — только на одном наборе фолдов.** Смена набора
   фолдов = смена эксперимента, а не улучшение.
3. **Сид фиксирован: 42.** Многократные сиды — отдельное семейство
   экспериментов (фабрика exp1000), а не способ «подтянуть» метрику.
4. **Критерий adoption формулируется до запуска** и записывается в карточку
   эксперимента (например, «≥0.5% на 3 из 4 фолдов», «fold_03 ≤ 1.69177»).
5. **In-sample числа не сравниваются с out-of-sample.** Блочная абляция
   (exp08) — только для сравнения блоков между собой.
6. **Проверка порядка строк сабмита.** `user_id` в сабмите должен совпадать
   с `sample_submit.csv` — иначе расчёт лидерборда бессмыслен.

## Статусы эксперимента

```
planned → running → done | rejected
```

Дополнительные статусы для подготовительных, но не обученных записей:
`data ready` (датасет фичей собран), `priors ok` (калибровочные артефакты
готовы), `infra` (построена инфраструктура, прогоны не сохранялись),
`not run` (скрипт готов, запуск не выполнялся).

## Формат карточки эксперимента

```markdown
## expNN — <название>  *(alias <старое имя>)*

- **Гипотеза**: ...
- **Метод**: ... (протокол: трейн fold_00..02 → вал fold_03, сид 42)
- **Результат**: ... (RMSLE fold_03 ± сравнение с ref, ключевые числа по фолдам)
- **Вывод**: adopted / rejected / next step
- **Артефакты**: код/отчёты/сабмит — пути
```

Исторические имена (`b01`, `b03`, `b05`, `e2`, `stack`, `exp025`) сохраняются
как алиасы в заголовке карточки.
